# shared 📚 — source files both teammates read / 兩人都會讀的原始資料

The AIs only read here; their work goes into `../outbox/`. / AI 只讀這裡，成品放 `../outbox/`。

- `campus-picker.html`: the "What can I do between classes?" picker. Double-click it to play. / 「課間我想做什麼？」挑選器，雙擊就能玩。
- Want to use your own page from last week instead? Rename your `index.html` to `campus-picker.html` and put it here (optional). / 想改用你上週自己的網頁：把 `index.html` 改名成 `campus-picker.html` 放進來蓋過去（選做）。
- `activities.json`: the 12 fictional activities the picker uses. / `activities.json`：挑選器用的 12 個虛構活動。
- Optional `log.md`: one line per thing the team learned about the captain, `- [YYYY-MM-DD] ...`. / 可選 `log.md`：學到小隊長的習慣就記一行。

All activities are fictional teaching examples. / 活動全部是虛構的教學範例。
